# Подключение сессии YouTube из файла

23 ноября 2026 года

Правило хранения выбора обновлено в версии 1.0.21. [Сохранение источника сессии](0005-remember-youtube-session-source.md)

Пользователь при необходимости выбирает экспортированный файл cookies формата Netscape. Окно хранит путь к файлу в памяти до отключения сессии или закрытия приложения.

`yt-dlp` поддерживает `--cookies` и может записывать обновлённые cookies обратно. Для каждой операции приложение формирует отдельную временную копию только с записями YouTube. Её получают проверка ссылки и скачивание видео или MP3 по HTTPS-ссылкам YouTube. После завершения процесса копия удаляется. При закрытии окна во время такой операции приложение запрашивает отмену и ждёт удаления копии. [Документация yt-dlp](https://github.com/yt-dlp/yt-dlp#filesystem-options)

Сессия остаётся доступной на время работы приложения. Срок действия cookies, доступ аккаунта к видео и прохождение проверки определяет YouTube. [Документация сессий YouTube](https://github.com/yt-dlp/yt-dlp/wiki/Extractors#exporting-youtube-cookies)
