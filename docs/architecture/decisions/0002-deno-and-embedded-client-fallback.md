# ADR-0002: Deno и резервный встроенный клиент YouTube

Дата: 1 сентября 2026 года  
Статус: принято

## Контекст

Часть публичных роликов возвращает `UNPLAYABLE` для автоматически выбранного клиента `visionOS`. Обычный web-клиент видит страницу, но из-за SABR и JavaScript-челленджей не предоставляет медиaформаты без PO Token. В Chrome те же ролики воспроизводятся.

## Решение

- Поставлять переносимый `deno.exe` в локальной папке `tools` и передавать его yt-dlp через `--js-runtimes`.
- Запрашивать ответы клиентов `default,web_embedded`: основной клиент сохраняет совместимость, а встроенный служит резервом для ложного `This video is not available`.
- Не читать cookies Chrome автоматически и не передавать данные аккаунта YouTube.

## Последствия

Больше публичных роликов загружается без авторизации и без системной установки Deno. Размер переносимой поставки увеличивается. Видео с настоящим возрастным, региональным, приватным или аккаунтным ограничением могут остаться недоступными; для них потребуется отдельная, явно разрешённая пользователем поддержка cookies.
