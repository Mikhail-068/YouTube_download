# Подключение сессии из браузера

23 ноября 2026 года

Пользователь выбирает профиль Firefox, Chrome или Edge в меню «Сессия YouTube». Настройки приложения содержат имя браузера и путь к профилю. Команда «Отключить сессию» удаляет этот выбор. Сканирование стандартных папок профилей выполняется при открытии меню и проверяет наличие файлов настроек браузера.

При выполнении действий по HTTPS-ссылкам YouTube оркестратор передаёт профиль `yt-dlp` через `--cookies-from-browser`. Запуск с браузерной сессией использует экстракторы YouTube, отключает внешние конфигурации `yt-dlp` и экспорт cookie-файла. Чтение cookies выполняет `yt-dlp` в момент операции. [Параметры yt-dlp](https://github.com/yt-dlp/yt-dlp#filesystem-options)

Доступ зависит от настроек браузера, входа в выбранном профиле и ответа YouTube. При ошибке чтения профиля доступен импорт файла в том же меню. [Решение об импорте файла](0003-youtube-session-from-cookie-file.md)
