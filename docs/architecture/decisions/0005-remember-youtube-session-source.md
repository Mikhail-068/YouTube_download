# Восстановление источника сессии при запуске

24 ноября 2026 года

Выбор файла Netscape сохраняется вместе с настройками сессии, чтобы пользователю не приходилось повторять настройку после запуска. Для совместимости с версией 1.0.20 используется прежний файл настроек. Он содержит только путь к экспортированному файлу либо пару «браузер и профиль».

При запуске приложение проверяет наличие выбранного файла. При отсутствии файла оно предлагает выбрать его заново. Проверка содержимого и создание временной копии по-прежнему происходят при операции с YouTube. Команда «Отключить сессию» удаляет сохранённый выбор. Срок действия браузерной сессии определяется YouTube.
